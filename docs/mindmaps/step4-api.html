3 设计理由 · 例子
为什么 net/http？零新依赖；Go 1.22 PathValue 够用；以后可换 Hertz。
为什么先查 Trace 再 Spans？区分「不存在 404」和「存在但无步骤 200 []」。
为什么不用 GORM？API 只认 Storage；单测用 Memory 秒跑。
为什么不做 Metrics？聚合逻辑在 Step 6；本 Step 只做读 Trace。
