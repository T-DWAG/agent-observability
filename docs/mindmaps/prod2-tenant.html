实践篇 · 专题 2

租户与鉴权

tenant_id 围墙 · API Key → 租户 · /healthz 公开 · 跨租户 404

1 对照 · 两个词
概念作用落地
Tenant数据围墙obs_traces.tenant_id
Auth进门钥匙Bearer API Key → tenant
Session同租户内分组session_id（不能当围墙）
2 管道 
// 读路径
Bearer api_key
  → AuthMiddleware → ctx.tenant
  → GetTrace(tenant, id) / List(tenant=…)
  → 跨租户 404

// 写路径
Config.TenantID (空→default)
  → Trace.TenantID → SaveTrace
3 设计理由
Key 放环境变量？先立围墙；不做租户管理表，本地好调。
Span 不加 tenant？经 Trace 归属即可，少一列心智负担。
GetTrace 显式传 tenant？比藏 context 好调试、好测。
跨租户为何 404？不泄漏「别家有没有这条 id」。
