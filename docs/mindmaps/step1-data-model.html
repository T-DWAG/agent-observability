3 设计理由 · 例子
为什么三张表？Trace 看整次、Span 看单步、Evaluation 看质量 — 查询场景不同。
为什么 Span 宽表？一行一步骤，按 type 填不同列，查时间线比拆表简单。
为什么 Trace 冗余 token？列表页直接读 Trace，不用每次 SUM Span。
场景结果
用户连续问 3 个问题3 个 Trace，1 个 Session
「北京天气？」一次执行1 Trace + 4 Span（agent→llm→tool→llm）
Span 树llm/tool 的 parent 都指向 agent Span
