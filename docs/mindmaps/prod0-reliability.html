3 设计理由
为什么继续丢弃而不是阻塞？观测不得拖垮 Agent；先保证「丢了能数清」。
为什么叫 NoContent 不叫 CaptureContent？bool 零值是 false；「开启」语义的字段零值会变成关闭，旧调用 silently 丢正文。
为什么 newState 不提前打码？策略只留在 applyContentPolicy，避免两处逻辑分叉。
为什么重试不 sleep？专题 0 求简单可测；退避留给以后。
为什么不做抽样？拍板里抽样属专题 3；本专题只装闸门。
为什么 TenantID 不落库？方向预留即可；改表会干扰本专题学习焦点。
