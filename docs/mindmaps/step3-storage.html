3 设计理由 · 例子
为什么要接口？Step 2 用 Memory 测采集；线上换 PG 一行构造，不用碰 handler。
为什么 OnConflict？按 span_id / trace_id 幂等；重试或重复 finish 不会 unique 冲突。
为什么现在加 Get*？Step 4 API 马上要查；本 Step 一并实现，避免接口二次撕裂。
为什么不做 Eval？评估是事后异步写，和采集落库解耦，留给 Step 5。
